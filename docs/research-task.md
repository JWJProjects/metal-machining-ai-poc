# 可重跑的研究任務
這是研究輸入與預期輸出，不是模型執行紀錄。

## 輸入
僅用 [研究依據與來源](research-brief.md) 所列的公開材料。不要上傳企業或設備私有資料，不使用需付款、登入的來源；不主動聯絡機關。所有擷取、辨識與摘要都要保留來源、段落和檢索限制。

## 逐步查核
1. 把工研院需求書拆成「必要交付」「允許資料」「待雙方確認」「時間與權利」四欄；逐項留頁碼，不從案名猜需求。
2. 以 NASA、NIST 公開資料確認「加工運轉條件與訊號相關的研究情境」；勿將其描述為本 PoC 的訓練資料或工研院指定來源。
3. 找至少一項可能比多訊號分類器更簡單的可用判讀規則，以及會讓模型結果不可靠的反例（取樣變動、訊號平線、工況漂移、只有單一類別）。
4. 交付研究摘要與驗收表，逐項分離事實、建議、未驗證與實際測得；不要把任何模擬成績外推至機台，也不可引用不存在的驗收。
