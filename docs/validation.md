# 轉序｜PoC 驗證紀錄

**範圍：合成序列、固定程式版本、本機預覽。採購需求參考與 PoC 結果分開。**

| 情境 | 輸入或操作條件 | 預期 | 實際 | 限制 |
|---|---|---|---|---|
| 可操作的代表模組 | 預載合成加工情境、三路訊號 | 切換情境或通道，檢視判讀和人工備註 | 穩定、短時擾動、顫振、負載偏移演示均由模式執行；五項 Node 測試通過 | 此方向須由採購雙方確認；未串機台 |
| 固定留出分割 | 18 批、432 訓練窗；另 10 批、240 測試窗 | 同批及完全一樣窗不重複；所有方法同樣本 | 獨立核對批次及原始樣本雜湊，兩組沒有重複 | 同一合成機制，不證明場域泛化 |
| 模型與規則 | 留出 90 異常、150 非異常 | 分別列漏報、誤報，允許規則更好 | 模型 9／0；雙訊號門檻 6／1；單振動門檻 16／123（順序為漏報／誤報） | 無合約門檻，不是診斷成績 |
| 失效輸入 | 錯誤取樣、缺通道、平線、無限值或超出支持範圍 | 不評分，不替換成「正常」；無分母比率為空 | 獨立查核七種畸形輸入皆不評分，餘數情境回傳 null | 支持範圍只是合成試驗設定 |
| 資料漂移 | 以相同保留窗調整振幅或模擬轉速 | 記錄受影響的成績與拒判，不當作額外獨立樣本 | 0.45× 振幅條件的模型召回率降至 80%；1.8× 拒判 45 窗；+22 rpm 壓力條件召回率 86.7% | 壓力條件來自同一批測試窗；不是出廠規格 |

## 架構與後續
合成器 → 分批訓練／保留 → 訊號特徵 → 多訊號邏輯迴歸／門檻規則 → 分流結果／JSON。人工備註不回寫模型，所有運算在本機瀏覽器。首次場測先約定合法資料來源、訊號粒度、校正、工況、離線讀取介面、可追溯標籤、拒判率、漏報誤報權衡和驗收隔離方式。成果與第三方授權按契約確認，這次無企業私有資料或正式驗收。

## 實機介面檢查
Qt WebEngine 於 1440 與 390 px 寬真實載入。可從振動切到轉速，選擇不支援取樣顯示「資料不支援」；兩種寬度無整頁橫向溢位，三列方法結果有渲染。JSON 測試紀錄可用 Node 重建並做位元組比對；瀏覽器的作業系統另存對話框不在本次檢查。
